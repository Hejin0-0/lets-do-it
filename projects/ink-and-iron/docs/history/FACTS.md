# Fact ledger (SPEC-AAA H-01)

Every historical statement the game makes is one row here. The game's text carries the row's ID
(`facts: [...]` on a campaign chapter, or a `// Fxx` note beside a line), and
`tests/rules/facts.test.ts` fails if an ID is used that this file does not hold (H-08).
Alternate history ("Your war") is the player's and is never stated as fact.
