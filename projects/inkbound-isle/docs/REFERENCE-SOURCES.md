# Modern Cartoon Rendering Sources

Only official sources define this pass. They inform quality criteria and API usage; no art or code is copied.

- Nintendo, [Animal Crossing: New Horizons – Nintendo Switch 2 Edition](https://animalcrossing.nintendo.com/new-horizons/nintendo-switch-2-edition/) — current 2026 reference edition and enhanced-graphics target.
- Nintendo, [official product listing](https://www.nintendo.com/us/store/products/animal-crossing-new-horizons-nintendo-switch-2-edition-121591/) — January 15, 2026 release and supported features.
- Three.js, [Color Management](https://threejs.org/manual/en/color-management.html) — sRGB annotations for color textures and renderer output.
- Three.js, [MeshToonMaterial](https://threejs.org/docs/pages/MeshToonMaterial.html) — nearest-filtered, no-color-space gradient maps and toon material maps.
- Three.js, [Shadows](https://threejs.org/manual/en/shadows.html) — shadow-map cost and inexpensive blob-shadow technique.
- Three.js, [Textures](https://threejs.org/manual/en/textures.html) — texture memory, filtering, and reuse considerations.

The Nintendo reference is used for general qualities—rounded shape language, clean material grouping, appealing animation, readable contact, and uncluttered composition—not for protected characters, geometry, textures, UI, or names.
