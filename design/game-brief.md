**One-sentence pitch:** 풀가의 의자에 앉아 시간과 지켜볼 것을 고르고, 바다를 떠도는 병 속 배와 사물 디오라마를 보트로 건져 도감의 페이지를 하나씩 채우는 조용한 관찰 게임.

## Core loop
- 의자에 앉아 지켜볼 러버덕과 시간을 고른다.
- 풍경과 풀을 지켜보고, 떠 있는 오리를 마우스로 잡아 장난친다.
- 가끔 바다에 병 속 배(Bottle Ship)나 사물 디오라마가 떠오면 보트를 보내 건져 온다.
- 건진 것이 도감의 빈 페이지를 채우고, 일어나 집으로 돌아간다.

## Player goal & fail state — what "working" looks like
- **목표:** 도감의 페이지를 모두 채운다. 페이지 수와 수집품 수가 같은 정해진 목록이라, "새 발견"은 곧 "빈 페이지 하나가 채워짐"이다.
- **실패:** 없다. 한 번의 방문은 새 페이지 하나가 채워지면 완성된 느낌이다. 건지지 못한 병은 다음에 다시 떠온다.

## MVP — what must exist to be the game
1. 앉은 상태와 앉으면 뜨는 메뉴(지켜볼 오리, 시간). 의자 옆 물건 하나와 실제 글자 몇 단어로 만든다(낭독기, 키보드, 터치가 쓰는 진짜 요소).
   - 사용자 결정(2026-11-01): 시간은 슬라이더로 아무 시각이나(15분 단위). 고른 뒤 시계는 계속 흐르되 하루가 30분. 오리를 지켜보면 자리는 그대로이고 시선이 그 오리를 따라간다. 오리를 지우는 방법은 필요 없다.
2. 일어서기.
   - 사용자 결정(2026-11-05): 앉은 메뉴에 Go home. 누르면 일어서고, 저녁으로 저물며 화면이 어두워지는 짧은 장면(약 4초, "See you tomorrow.") 뒤 같은 페이지에서 다음 방문이 바로 시작된다(도감과 풀의 물건은 그대로, 시계는 오후 3시). 의자는 지금 그대로 두고 나중에 사용자가 직접 바꾼다.
3. 바다를 떠도는 병 속 배와 사물 디오라마. 정해진 목록이다.
   - 사용자 결정(2026-11-01): 목록은 6개. 병 속 배 셋(돛단배, 증기선, 해적선), 디오라마 셋(화산섬, 밀림 섬, 눈 덮인 섬). 방문마다 하나, 앉고 15~45초 뒤 아직 못 찾은 것 중 무작위로 떠오른다. 떠오르는 곳은 바다 쪽 의자에서 보이는 바다. 보트는 떠 있는 것을 전부 한 번에 건진다. 그림은 디자인 보류라 임시 그림(병은 비치볼, 디오라마는 구명환)을 그대로 쓴다.
4. 보트를 보내 건지면 도감 페이지가 채워진다. 보트는 기존(`rescue.js`), 대상과 기록은 신규.
5. 도감 뷰: 페이지 넘기기, 빈 페이지와 채운 페이지. 데이터는 기존 `logbook.js`, 화면은 신규.
   - 사용자 결정(2026-11-04): 못 찾은 쪽은 종류만(A ship in a bottle / An island), 이름은 찾은 뒤에. 찾은 쪽은 이름, 찾은 날짜, 한 줄 설명. 열면 가장 최근에 찾은 쪽부터. 도감은 앉은 메뉴에서만 연다.
6. 도감 품목을 풀장에 소환.
   - 사용자 결정(2026-11-04): 소환한 것은 방문이 끝날 때까지 남고 다음 방문에도 그대로 떠 있다(도감과 함께 저장). 자리는 항목마다 정한 곳. 치울 때는 도감의 Send it back을 누르면 하늘의 갈매기가 내려와 낚아채 날아간다(잘 안 되면 나중에 도감 단추가 바로 치우는 것으로 바꿀 수 있음).

그대로 쓰는 기존 기능: 섬, 풀, 오리 순환, 오리 잡기와 던지기, 생물, 낮밤, 도감 저장.

## Out of scope — not building this
- 실패, 타이머, 강제 퀘스트, 점수 경쟁, 화폐, 멀티플레이, 새 지역.
- 레이스와 오리 꾸미기 화면. 로직(`world.js`)은 남지만 이번 메뉴에는 넣지 않는다.
- 보이는 디자인(색, 글꼴, 모양)은 보류한다. 휴대폰은 웹 다음이다(둘 다 보류 유지, 2026-11-05).

## Build order
1. 앉기, 앉은 상태, 일어서기. 모든 것의 틀이고, 메뉴는 자리만 잡아 둔다.
2. 병 하나가 떠오고, 보트로 건져, 도감 한 페이지가 채워진다. 가장 불확실한 핵심 재미라 먼저 증명한다.
3. 도감 뷰(페이지).
4. 앉은 메뉴에서 지켜볼 오리와 시간 고르기.
5. 수집품 여러 종 채우기와 풀장 소환.

---
**Who it's for / what they feel:** 압박 없이 몇 분 풀가에 앉아 있고 싶은 사람. 느긋함과 작은 호기심.

**Art & audio direction:** 그림은 보류(사용자 결정 대기). 소리는 사용자 녹음(2026-11-05, `projects/rubber-duck-pool/assets/04_audio`): 풀의 물결 소리가 바탕, 바다 파도 둘, 미끄럼틀·펌프·관에서 오리가 일으키는 물소리, 오리 디자인마다 제 목소리(탭하거나 집어 옮길 때). 만든 소리(음악, 바람, 새, 귀뚜라미, 불꽃놀이)는 꺼 둔다. 첫 터치나 키에 켜지고 M으로 끄고 켠다.

**Reference game:** Neko Atsume. 찾아온 것을 기다렸다가 도감에 모으는 부분만 가져온다. 보여 주는 방식은 사용자가 보여 준 타이틀 화면의 생각, 곧 장면 속 물건 하나와 그 옆의 몇 단어만 가져온다(이름, 글꼴, 그림, 문구는 가져오지 않음).
